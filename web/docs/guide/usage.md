# 使用说明

本页介绍文策 AI 的日常工作流。首次使用请先完成 [安装](/guide/installation) 和 [DeepSeek V4 Pro 配置](/guide/api-config)。

## 选择模型

聊天输入框旁的模型列表只显示已在 **设置 → 大模型** 中添加并启用的模型。推荐使用经过项目验证的 **DeepSeek V4 Pro**；模型还应支持 Tool Calling，否则无法可靠读取和修改文档。

## 选择 Agent 模式

| 模式 | 能力 | 适用场景 |
|---|---|---|
| **Agent** | 读取、搜索并修改文档，可调用子 Agent、Skill、文件和 MCP 工具 | 写作、润色、翻译、复杂编辑 |
| **Ask** | 只读取和分析，不生成或删除 Word 内容 | 文档问答、总结、资料查询 |
| **Plan** | 多个专家 Agent 规划、研究、写作和审阅 | 长文、研究报告、复杂工作流 |

简单任务优先使用 Agent；只想提问且不希望修改文档时使用 Ask；需要多阶段协作时使用 Plan。

## 如何提问

在输入框中描述目标、范围和输出要求。需要处理特定文字时，可以先在 Word 中选中文本，再点击添加选区。

| 场景 | 示例 |
|---|---|
| 生成文章 | `写一篇 1500 字的人工智能行业趋势分析，包含三级标题和总结。` |
| 修改内容 | `将选中的三段改成正式的项目汇报语气，保留事实和数字。` |
| 文档问答 | `总结当前文档的核心结论，并列出支撑每个结论的段落。` |
| 调研写作 | `使用已配置的搜索 MCP 调研近期政策，再撰写一份带来源的分析。` |
| 使用 Skill | `使用 internal-comms Skill，将当前内容改写成公司内部周报。` |

复杂任务建议先说明不能改变的内容，再说明预期结构、篇幅、语气和是否需要外部资料。

## 文档操作确认

Agent 或 Plan 模式准备修改文档时，加载项会展示待确认的生成或删除操作：

- 点击 **确认** 后写入文档。
- 点击 **取消** 则放弃本次修改。
- 校对显示方式可在 **设置 → 通用 → 校对显示模式** 中切换。

## 主要控件

- **发送/停止**：开始或中止当前任务。
- **新建会话**：开始新的上下文，不会删除旧历史。
- **选区/附件**：将当前 Word 选区或本地文件加入上下文。
- **深度思考**：允许兼容模型使用思考模式。
- **设置**：管理界面语言、模型、个性化、MCP、Skill 和数据。

## 智能体工具

| 工具 | 作用 | Agent | Ask | Plan |
|---|---|:---:|:---:|:---:|
| `read_document` | 读取 Word 内容 | ✅ | ✅ | ✅ |
| `search_document` | 按文本或格式定位段落 | ✅ | ✅ | ✅ |
| `generate_document` | 生成并插入结构化内容 | ✅ | ❌ | ✅ |
| `delete_document` | 删除指定段落 | ✅ | ❌ | ✅ |
| `load_skill_context` | 加载已启用 Skill | ✅ | ✅ | ✅ |
| 文件工具 | 读取和编辑任务文件 | ✅ | ✅ | ✅ |
| `python_repl` | 执行数据处理代码 | ✅ | ❌ | ❌ |
| MCP 工具 | 调用已启用的外部服务 | ✅ | 视配置而定 | ✅ |

具体工具分配会随 Agent 角色和版本调整，界面不需要用户手动选择工具。

## 设置建议

- 界面语言支持简体中文和 English，可在 **设置 → 通用** 切换。
- Temperature 默认 `0.5`，范围为 `0-1`。
- 不使用的 MCP 和 Skill 建议关闭，减少误调用。
- 长期记忆只保存希望跨会话保留的信息，敏感信息不要写入长期记忆。

遇到问题请查看 [常见问题](/guide/faq)。
