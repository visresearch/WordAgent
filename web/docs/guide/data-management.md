# 数据管理

![](/data.png)

## 清除缓存

文档解析、图片处理和文件上传会在项目的 `temp` 与 `uploads` 目录中产生缓存。点击 **扫描** 查看文件数量与占用空间，点击 **清除缓存** 删除这些目录中的缓存文件，操作结果在页面内显示。

## 长期记忆

长期记忆是AI的持久化记忆，影响AI对您的长期理解（越靠上越旧，越靠下越新）。每一行代表一条记忆，用户可以手动编辑长期记忆，也可以通过AI的提示词来影响AI的长期记忆。

通过 **启用长期记忆** 开关控制是否使用记忆，开关修改会立即保存。编辑记忆内容后点击 **保存记忆**；点击 **刷新** 则重新读取已保存的内容。

## 删除所有数据

当前 **删除所有数据** 按钮用于清空聊天会话及消息记录。在页面内的确认框输入 `DELETE` 后执行；点击 **取消** 可关闭确认框。删除失败时显示原因并保留重试入口。

此操作不会重置 API Key、提供商、模型参数、Skill、插件或长期记忆。缓存文件通过上方的 **清除缓存** 单独管理。
