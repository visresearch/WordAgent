# Skill Revision Comparison

When comparing two revisions, evaluate them against the same realistic prompts. Prefer the revision that:

- triggers on the intended requests without overreaching
- follows WordAgent's available tool and document workflows
- produces accurate, complete output with fewer unnecessary steps
- handles missing inputs and edge cases clearly
- stays within Markdown loading limits

Explain the decision with observable differences. Do not prefer a longer skill merely because it contains more instructions.
